## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/CyberSG-Zero/astro-portfolio.git

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:4321](http://localhost:4321) to view.
